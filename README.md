# HR Employee Analytics — Attrition Analysis

## 📌 Project Overview

This project analyzes employee data to identify patterns and factors associated with employee attrition. The analysis uses Python for data cleaning and exploratory data analysis, and Microsoft Power BI for interactive dashboard development.

The objective is to help HR teams understand attrition patterns and identify areas that may require further investigation.

## 🎯 Business Objectives

- Analyze overall employee attrition.
- Identify attrition patterns across departments.
- Examine the relationship between overtime and attrition.
- Analyze attrition by job role, income, tenure, and job satisfaction.
- Develop an interactive HR analytics dashboard.
- Provide data-driven observations and recommendations.

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Microsoft Power BI**
- **DAX**
- **CSV Data**

## 🔄 Project Workflow

1. Load the HR dataset using Python.
2. Perform data quality checks.
3. Identify missing values and duplicate records.
4. Remove constant and unnecessary columns.
5. Perform exploratory data analysis.
6. Calculate HR and attrition KPIs.
7. Build an interactive Power BI dashboard.
8. Develop business insights and recommendations.

## 🔍 Key Observations

- Employees working overtime have a higher observed attrition rate in this dataset.
- Attrition rates vary across departments.
- Lower income groups show higher observed attrition rates.
- Lower job satisfaction ratings are associated with higher observed attrition rates.

These observations describe associations in the dataset and do not establish that any factor directly causes employee attrition.

## ⚠️ Limitations

This is a historical, observational dataset. The findings should be validated using current HR data, employee surveys, and exit interview information before making business decisions.
